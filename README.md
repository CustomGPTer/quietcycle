# QuietCycle

QuietCycle is a free Android period and cycle diary that has no internet permission, so nothing you log can leave your phone. Honest date ranges instead of a single guess, 44 short guides drawn from NHS pages, a PDF for your GP, a password-locked backup and discreet reminders. No adverts, no account.
